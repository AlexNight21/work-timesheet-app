# work-timesheet-app

Web-приложение для заполнения табеля учёта рабочего времени и выгрузки Excel-отчёта.

## Запуск

```bash
uv sync
uv run app/main.py               # запуск напрямую
# или
uv run fastapi dev app/main.py   # режим разработки с авто-перезагрузкой
```

Откройте http://127.0.0.1:8000.

## Возможности

- Выбор компании, сотрудника, подразделения и менеджера из txt-справочников.
- Добавление новых значений прямо на странице (файлы создаются автоматически).
- Выбор даты заполнения и периода отчёта.
- Заполнение рабочих дней по неделям: время начала/окончания, обед, проекты и
  проведенные работы. В день можно добавить несколько проектов.
- Отметка отсутствия сотрудника с указанием причины: плановый отпуск, отпуск за
  свой счёт, больничный, праздничный день или своя причина.
- Формирование и скачивание Excel-отчёта. Отчёт создаётся с нуля; шаблон
  `data/template/timesheet_template.xlsx` используется только как образец и не
  требуется при запуске.

Данные хранятся в `data/storage/`, готовые отчёты — в `data/reports/`.
